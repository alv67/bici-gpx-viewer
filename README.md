# Bici GPX Viewer

Viewer locale single-file per percorsi bici `.gpx`.

- Apri `index.html` nel browser, trascina i GPX
- Fix automatico tracce con salti spuri (soglia interna 1°)
- Mappa Leaflet + statistiche: distanza, durata, media
- Indirizzi partenza/arrivo via Nominatim

## Nota

Creata per visualizzare le esportazioni tracce dell'app PinBike, il cui GPX non è pienamente conforme allo standard (coordinate assolute mescolate a delta relativi, corrette con soglia interna 1°). Per altri formati l'app andrà aggiornata di conseguenza.

Nessuna build, nessun server.
